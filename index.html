Misi Penyelamatan Data:
Dasar Keamanan Siber

Pertanyaan Pemantik: Kalau ada pesan hadiah gratis, kamu klik atau kamu cek dulu?

🎯 Tujuan Belajar: Kamu akan belajar mengenali phishing, membuat kata sandi kuat, dan mengamankan akun dengan langkah yang benar. Kamu akan melatih pengambilan keputusan, pemecahan masalah, dan manajemen waktu seperti di dunia kerja IT.

🧩 Deskripsi: Halo teman-teman! Server sekolah diserang! Bantu Tim IT menyelamatkan data dalam 3 misi. Setiap jawaban benar menambah skor. Hati-hati, nyawamu hanya 3! Selesaikan semua misi dan jadi Pahlawan Siber!

Rasio 16:9 • Single Page • Tanpa Internet • Visual teks + ikon

📖 Panduan Bermain

🎮 Cara Main

1. Baca soal dengan teliti.
2. Pilih jawaban / klik pasangan / urutkan langkah.
3. Kamu langsung dapat umpan balik benar/salah.
4. Selesaikan Misi 1, 2, dan 3.

🏆 Aturan

• Jawaban benar = +100 poin
• Jawaban salah = -1 nyawa
• Waktu total 3 menit
• Nyawa habis = ulang dari Misi 1

Navigasi: Kamu bebas pilih menu di bawah. Kamu bisa kembali ke Menu kapan pun. Gunakan tombol Berikutnya / Kembali yang selalu ada.

🗺️ Menu Misi

Progres: 0 dari 3 misi

MISI 1: Jebakan Phishing

Pilih tindakan paling aman saat dapat pesan mencurigakan.

MISI 2: Pasangkan Ancaman

Cocokkan jenis serangan dengan contohnya.

MISI 3: Urutan Aman

Urutkan 4 langkah mengamankan akun yang diretas.

📝 EVALUASI

Kuis singkat 2 soal untuk cek pemahamanmu.

Misi 1 dari 3: Jebakan Phishing 🎣

Studi Kasus: Rina dapat SMS: "Selamat! Kamu menang HP gratis. Klik http://hadiah-gratis-123.xyz untuk klaim!" Apa yang harus Rina lakukan?

Misi 2 dari 3: Pasangkan! 🧩

Klik 1 kotak kiri, lalu klik pasangannya di kanan. Pasangan benar akan jadi hijau.

PHISHING
KATA SANDI LEMAH
WIFI PUBLIK
123456
Transaksi bank di wifi cafe tanpa VPN
Link palsu minta data login

Misi 3 dari 3: Urutkan Langkah 🔢

Klik langkah secara berurutan dari yang paling pertama dilakukan saat akun diretas:

Aktifkan verifikasi 2 langkah
Ganti kata sandi segera
Periksa aktivitas login & laporkan
Keluar dari semua perangkat lain

📝 Evaluasi: Cek Pemahamanmu

Soal 1: Ciri kata sandi yang paling kuat adalah?

Soal 2 Reflektif: Tulis di buku: Apa yang akan kamu lakukan jika temanmu membagikan password-nya kepadamu? Diskusikan dengan teman sebangkumu.

✅ Kamu sudah melatih problem solving, pengambilan keputusan, dan manajemen waktu. Kompetensi ini penting untuk pekerjaan IT Support, Admin Jaringan, dan Teknisi.

🎉 HASIL AKHIR

Skor: 0

Yang kamu pelajari: 1) Jangan klik link mencurigakan, 2) Kenali jenis serangan siber, 3) Urutan mengamankan akun: Ganti password → Aktifkan 2FA → Logout perangkat → Cek aktivitas.
